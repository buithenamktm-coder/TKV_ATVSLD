# MiningVolume HS-Next

Mã nguồn MiningVolume HS-Next dành cho AutoCAD 2023 được đặt tách biệt trong repo TKV_ATVSLD theo yêu cầu của chủ dự án.

- Phiên bản hiện tại: v0.9 Pre-Release
- Thư mục nguồn: `tools/MiningVolume_HSNext/v0.9`
- Workflow build Windows: `.github/workflows/build-miningvolume-autocad2023.yml`
- Mục tiêu: build DLL net48, đóng bundle AutoCAD 2023 và tạo Setup không cần Build Tools trên máy người dùng.

Phần này độc lập với mã nguồn ATVSLĐ hiện hữu.
