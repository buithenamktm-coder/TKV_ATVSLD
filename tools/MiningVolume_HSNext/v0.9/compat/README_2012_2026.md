# IMSAT VOLUME V2.0 — Ma trận triển khai AutoCAD 2012–2026

**Release gate: BLOCKED until each claimed host passes interactive runtime tests.**
This is an extension of the existing IMSAT VOLUME project. The mathematical
engine must remain common: TIN, profiles, grid cut/fill, CAD table and XLSX
must not be reimplemented in different version adapters.

## Work already committed
- Four existing C# projects accept the shared `IMSATCadFlavor` setting.
- Version-aligned, isolated builds in `compat/build_compat.ps1`.
- CI in `.github/workflows/imsat-cad-2025-2026-compat-ci.yml`.
- `target_matrix.json` is the canonical per-host gate/status inventory.
- No 2023 assembly is relabeled or advertised as working on another CAD.
- Default AutoCAD 2023 build and its 2023-restricted bundle are preserved.

## Packaging and installation — gate requirements
1. Enumerate installed AutoCAD releases, architecture and update/CLR;
   refuse unknown combinations (especially R25.0 and R25.1 without runtime detection).
2. One version-specific managed module per host; install into an ApplicationPlugins
   bundle with truthful `RuntimeRequirements`. Do NOT distribute Autodesk DLLs.
3. Do not select a .NET 8 or .NET 10 payload on CAD year alone.
4. Reuse the current IMSAT icon, Ribbon/menu, author attribution and application data.
5. Installation, repair, rollback and uninstallation must not delete DWG, DXF,
   saved projects, licenses or functioning V2.0 features.
6. Do not change `FILEDIA`, `CMDDIA` or AutoCAD keyboard shortcuts.

## Runtime acceptance matrix (for EACH promised version)
- Load/no crash: DLL, Ribbon/Menu, palette open/close, licensing and hotkeys.
- Source: POINT, LINE/POLYLINE, contours and closed boundary, read XY/Z.
- TIN: duplicated XY/multiple Z, walls, large datasets, cancellation, save/reopen.
- Profiles: generate/edit/recalculate/cancel; use official 3 formulas and level bands.
- Grid: >5000 cells, coincident area, rotated grid, cut/fill in same cell,
  reject real overlapping planar surfaces, compare against `KL mb.dxf`.
- CAD TABLE: all column headings, units, totals and Arial.
- XLSX: full wrapped headings, linked formulas, selective IMSAT logo.
- Installer: fresh installation, upgrade, rollback, remove, startup automation,
  version update and coexistence with other AutoCAD releases.

**No 'supports 2012–2026' declaration may be placed on a setup until these
host-runtime gates have written PASS evidence for all claimed years.**
